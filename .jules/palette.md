## 2025-05-04 - Adding ARIA attributes to interactive React icons
**Learning:** Icon-only buttons using generic SVG components like those in `lucide-react` provide no context to screen readers, making interactive features completely inaccessible to visually impaired users. When keyboard focus styles are absent, sighted keyboard users cannot navigate the interface either.
**Action:** Always wrap interactive icon elements in a button, provide a descriptive `aria-label`, attach an `aria-hidden="true"` attribute to the inner SVG to avoid confusing screen readers with non-text visual nodes, and append `focus-visible:ring-2 focus-visible:ring-[color] focus:outline-none` for keyboard visibility. Dynamic elements like accordions or menus should also track state using `aria-expanded`.
