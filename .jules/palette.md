## 2024-06-12 - Playwright Test Harness for React Components
**Learning:** When trying to verify visual and interactive frontend changes (like focus rings) using Playwright, relying on Vite server and intercepting backend APIs can be brittle and often leads to timeouts or proxy errors if the route mocking isn't exact or if Vite fails to render standalone files correctly.
**Action:** A more robust approach for verifying isolated UI components is to create a standalone HTML file that loads React, Babel, and Tailwind via CDN, mock the necessary components and imports directly within a `<script type="text/babel">` block, and serve it via Python's built-in `http.server` (e.g., `python -m http.server 8080`). This guarantees the component mounts cleanly without app-level dependencies.
