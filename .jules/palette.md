## 2024-05-18 - Missing focus states and relying purely on titles for list items
**Learning:** Icon-only action buttons within list items throughout the app rely on the `title` attribute for context but lack explicit `aria-label`s, which are essential for robust screen reader support. Furthermore, focus rings are omitted, obscuring keyboard navigation usability.  This pattern is evident in the `Sources.tsx` file and likely pervasive across other map-rendered list components like `Editorial.tsx` or `Schedule.tsx`.
**Action:** Always provide explicit `aria-label` text equivalent to the `title` text for icon-only action buttons. To ensure clear visual focus indication, consistently append explicit focus classes (`focus-visible:ring-2 focus-visible:ring-maya-500 focus:outline-none`) and use `aria-hidden="true"` on inner decorative SVGs.
