## 2024-05-18 - Missing Screen Reader Context and Focus Styles on Icon-Only List Action Buttons
**Learning:** Icon-only action buttons arranged in list/table rows (e.g., 'Edit', 'Delete', 'Toggle') frequently lack both `aria-label`s and proper keyboard focus indicators (`focus-visible:ring-2`), making them completely inaccessible to screen readers and difficult to navigate via keyboard. This is a common pattern in dashboard CRUD tables.
**Action:** Always verify that icon-only buttons in row-level actions include descriptive `aria-label`s, hide their decorative SVGs from screen readers via `aria-hidden="true"`, and explicitly define focus visible utility classes (`focus-visible:ring-2 focus-visible:ring-maya-500 focus:outline-none`) so they are discoverable and actionable by all users.
